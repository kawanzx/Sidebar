# Sidebar Lateral Responsiva

Este projeto oferece uma **sidebar lateral responsiva** feita com **HTML** e **CSS**, ideal para navegação em sites e aplicativos.

## Funcionalidades

- **Expansão ao passar o mouse**: A sidebar começa compacta, mostrando apenas ícones. Quando o usuário passa o mouse sobre ela, os textos dos itens de navegação aparecem.
- **Responsiva**: A sidebar se ajusta ao tamanho da tela, funcionando bem em dispositivos móveis e desktops.
- **Navegação fácil**: Cada item de navegação é representado por um ícone e um texto explicativo.

## Como Funciona

- A sidebar começa estreita, exibindo apenas os ícones.
- Ao passar o mouse sobre a sidebar, ela expande para mostrar o texto.
- A animação de expansão é suave e a sidebar se adapta ao tamanho da tela.

## Personalização

Você pode personalizar os itens da sidebar, como links e ícones, além de ajustar a largura e as cores para se adequar ao seu projeto.
